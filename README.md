# Biblioteca Musical

Proyecto académico en Java para gestionar una biblioteca musical desde la terminal.

## Requisitos
- JDK de Java instalado (Java 8 o superior).
- Git (opcional, para clonar el repositorio).

## Descargar el proyecto
```bash
git clone https://github.com/fercho20-lab/proyecto-dsoo.git
cd proyecto-dsoo
```

## Compilar
Ejecuta el comando desde la carpeta donde están los archivos `.java`:

```bash
javac *.java
```

## Ejecutar
```bash
java Principal
```

## Funcionalidades
- Ver catálogo, buscar contenido y filtrar por género.
- Consultar la discografía de artistas.
- Reproducir y pausar canciones y podcasts (simulación por consola).
- Crear playlists, agregar y quitar contenido.
- Marcar y quitar favoritos.
- Consultar estadísticas de canciones, podcasts y reproducciones.

## Archivos principales
Las clases están en el paquete predeterminado y se encuentran en la raíz del repositorio. No se necesita configurar un IDE para compilar y ejecutar.
